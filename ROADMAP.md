# Personal AI Workflow Hub

## Цель

Создать систему, где Telegram служит главным входом для задач, идей и голосовых сообщений, а AI-агенты помогают классифицировать, планировать и автоматизировать работу.

## MVP

Первая рабочая версия должна уметь:

1. Принимать текстовые сообщения из Telegram.
2. Отправлять сообщение в AI-модель.
3. Получать структурированный разбор задачи.
4. Возвращать понятный ответ в Telegram.
5. Позже сохранять задачи в базу данных.

## Первая Архитектура

```text
Telegram
-> Telegram Bot
-> FastAPI backend
-> OpenAI API
-> FastAPI backend
-> Telegram
```

## Этапы

### Этап 0. Подготовка

- Создать Telegram-бота через BotFather.
- Получить Telegram bot token.
- Получить OpenAI API key.
- Установить Python.
- Создать папку проекта.

### Этап 1. Простой Telegram-бот

- Запустить FastAPI-сервер.
- Добавить endpoint для webhook.
- Научиться принимать сообщения.
- Научиться отвечать в Telegram.

### Этап 2. AI-анализ входящего сообщения

- Подключить OpenAI API.
- Отправлять текст пользователя в модель.
- Получать JSON с типом задачи, названием, приоритетом и рекомендуемым агентом.
- Запускать Planner Agent для задач планирования.

### Этап 3. Хранение задач

- Подключить PostgreSQL.
- Создать таблицы users, messages, tasks.
- Сохранять входящие сообщения и результаты анализа.
- Для MVP используется SQLite файл `workflow.db`, чтобы не поднимать отдельный сервер базы данных.
- Команда `/задачи` показывает последние сохраненные задачи.
- Команда `/сегодня` показывает активные задачи.
- Команды `/готово ID` и `/отмена ID` меняют статус задачи.
- Под списком задач есть inline-кнопки `Готово #ID` и `Отмена #ID`, чтобы не вводить номер вручную.
- Задачи могут автоматически попадать в проекты, чтобы Planner Agent видел направления работы, а не только отдельные задачи.

### Этап 4. Голосовые сообщения

- Получать voice message из Telegram.
- Скачивать аудио.
- Распознавать речь.
- Передавать текст в тот же pipeline.
- Голосовые сообщения обрабатываются через OpenAI transcription API.
- Текстовые задачи и аудио-транскрипция используют разные модели: `OPENAI_MODEL` и `OPENAI_AUDIO_MODEL`.

### Этап 5. Простые агенты

- Inbox Agent: понимает входящее сообщение.
- Planner Agent: разбивает задачи на структурированный план с целью, этапами, материалами, рисками, вопросами и первым шагом.
- Writer Agent: пишет тексты.

### Этап 6. Автоматизации

- Добавить очередь задач.
- Добавить расписание.
- Добавить подтверждения для рискованных действий.

### Этап 7. Notion-like панель

- Сделать web-интерфейс.
- Показать inbox, задачи, проекты, агентов и автоматизации.

## Главный Принцип

Сначала строим надежный входящий ящик в Telegram. Потом добавляем агентов, базу, голос, автоматизации и интерфейс.
